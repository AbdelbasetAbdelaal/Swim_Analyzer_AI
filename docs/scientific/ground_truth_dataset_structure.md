## 1. Overview & Privacy Principles

This document defines the storage layout, directory contracts, and privacy requirements for physical Ground Truth datasets used to validate the Swim Analyzer AI biomechanics engine.

### Strict Privacy & Repository Rules
1. **Never Commit Raw Swimmer Videos to Git:**
   - Raw video files depicting identifiable athletes must **never** be committed to version control.
   - Video files are stored locally or on secure institutional storage systems with encrypted access controls.
   - Only machine-readable annotations, schemas, anonymized metadata, and manifest pointers are tracked in Git.
2. **Participant Pseudonymization:**
   - Real names, team names, birthdates, and direct personal identifiers must not appear in directory paths, filenames, or annotation JSON files.
   - Identifiers must follow standard pseudonym format: `PARTICIPANT-XXX` or `SWIMMER-XXX`.

## 2. Directory Structure

The standardized ground truth storage layout is located under `data/ground_truth/`:

```text
data/
└── ground_truth/
    ├── raw/                 # Local video storage (untracked, gitignored)
    ├── annotations/         # Standardized Ground Truth JSON files (schema 1.0.0)
    ├── metadata/            # Pseudonymized participant demographics & camera calibration
    ├── manifests/           # Official & experimental manifests (JSON)
    ├── quality_control/     # Inter-rater agreement audits, ICC reports, adjudications
    └── validation_runs/     # Machine-readable output reports from validation executions
```

### Directory Specifications

| Directory | Purpose | Retention / Version Control Policy |
|---|---|---|
| `data/ground_truth/raw/` | Holds raw MP4/MOV high-speed video recordings. | **Untracked / Gitignored.** Files placed here manually by researchers or mounted via network share. |
| `data/ground_truth/annotations/` | Contains single-trial annotation files formatted according to `schemas/ground_truth_schema.json`. | Version controlled. Each file named `<sample_id>_annotation.json`. |
| `data/ground_truth/metadata/` | Contains pool dimension calibrations, camera lens intrinsic parameters, and participant pseudonym maps. | Version controlled (strictly anonymized). |
| `data/ground_truth/manifests/` | Official and candidate cohort manifests formatted according to `schemas/ground_truth_manifest_schema.json`. | Version controlled. Specifies trial eligibility and split isolation. |
| `data/ground_truth/quality_control/` | Dual-rater raw sheets, disagreement adjudication forms, and inter-rater reliability logs ($ICC$, Cohen's $\kappa$). | Version controlled. |
| `data/ground_truth/validation_runs/` | Timestamped evaluation outputs generated by `analysis/validation/ground_truth_runner.py`. | Version controlled / archived per release tag. |

## 3. Local & External Dataset Registration Mechanism

To evaluate an external or locally stored dataset without committing large binary video files to Git:

### Step 1: Place Videos Locally or on Mounted Storage
Place video files in `data/ground_truth/raw/<stroke>/` or a dedicated external directory (e.g., `/mnt/swim_validation_nas/videos/`).

### Step 2: Compute Cryptographic Hashes
For each video file, calculate its SHA-256 checksum:
```bash
sha256sum path/to/video.mp4
```
This ensures reproducible tracking of the exact binary video asset without storing the media in Git.

### Step 3: Produce Standardized Annotation File
Create an annotation JSON file in `data/ground_truth/annotations/` adhering to `schemas/ground_truth_schema.json`:
```json
{
  "sample_id": "GT-FREE-001",
  "participant_id": "PARTICIPANT-001",
  "session_id": "SESS-2026-09-A",
  "stroke_type": "Freestyle",
  "video_id": "VID-FREE-001",
  "video_filename": "freestyle_trial_01.mp4",
  "source_type": "HIGH_SPEED_OPTICAL_DUAL_RATER",
  "annotation_version": "1.0.0",
  "annotator_id": "EXPERT-RATERS-A-B-CONSENSUS",
  "annotation_timestamp": "2026-09-06T10:00:00Z",
  "video_fps": 60.0,
  "video_duration": 12.5,
  "frame_count": 750,
  "pool_context": {
    "pool_length_m": 50.0,
    "water_type": "Freshwater",
    "lane_width_m": 2.5,
    "camera_position": "Submerged_Window",
    "calibration_type": "Metric_Physical_Pool"
  },
  "demographics": {
    "sex": "Female",
    "age_group": "Senior_National",
    "competition_level": "National"
  },
  "cycle_annotations": [...],
  "metric_annotations": {...},
  "quality_flags": {
    "occlusion_level": "LOW",
    "lighting_quality": "HIGH",
    "tracking_confidence": 0.98
  },
  "exclusion_status": "INCLUDED",
  "exclusion_reason": null
}
```

### Step 4: Register in Manifest
Add the sample record to `data/ground_truth/manifests/ground_truth_manifest.json`.

The runner will verify the video path, validate the SHA-256 hash, ensure `exclusion_status == "INCLUDED"`, and execute the comparison.
